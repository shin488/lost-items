# なくしもの探知機（Lost Items Finder）

Flet Web アプリ（Pyodide / GitHub Pages デプロイ）  
🔗 **https://shin488.github.io/lost-items/**

忘れ物を見つけるまでの時間を減らすための、アイテム別忘れ物検索・記録・分析アプリ。

---

## フローチャート

### 1. アプリ全体のフロー

```mermaid
flowchart TD
    Start(["アプリ起動 / ページロード"]) --> Load["localStorageから<br/>記録・カテゴリ・間取りを読み込み + refresh"]

    Load --> T1["タブ: 探す"]
    Load --> T2["タブ: 記録"]
    Load --> T3["タブ: 間取り"]
    Load --> T4["タブ: ランキング"]
    Load --> T5["タブ: 分析"]

    T1 --> S0["アイテム名を入力<br/>または履歴チップ / ランキングから検索"]
    S0 --> S1{"空欄？"}
    S1 -->|はい| S2["スナックバー表示"]
    S2 --> S3["結果リセット"]
    S1 -->|いいえ| S4["unified_predict 実行"]
    S4 --> S5{"結果はある？"}
    S5 -->|いいえ| S6["該当する記録がありません"]
    S5 -->|はい| S7["結果カード表示<br/>場所 / 割合 / 根拠 / トップ判定"]

    T2 --> R0["なくした物・見つかった場所を入力して「記録する」"]
    R0 --> R1{"バリデーション OK？"}
    R1 -->|いいえ| R2["スナックバー表示"]
    R2 --> R0
    R1 -->|はい| R3["保存 + スナックバー「記録しました」+ フォームクリア"]
    R3 --> R4["履歴に追加 + refresh"]
    R4 --> R5{"見つけた？"}
    R5 -->|はい| R6["解決押下で resolved を true にする + スナックバー表示"]
    R5 -->|いいえ| T1
```

### 7. アプリ内の操作フロー（詳細）

## 補足

- 検索（フローチャート 2）は `predict.py` の RWR（Random Walk with Restart）による<br>
  アイテムと場所の関連グラフの推論と、記録の時刻情報（曜日・時間・経過日数）を組み合わせた加重集計で動作する。
- 未解決の記録は「見つけた」を押すと `resolved` フラグが立ち、分析タブの<br>
  解決率・発見までの時間に反映される。
- フローチャートはコードベースの変更に合わせて随時更新する前提。
