# 今後の展望（Future Outlook）

**なくしもの探知機**（Lost Items Finder）の今後の開発・改善計画についてまとめる。

## 1. 分析タブの中身のアルゴリズム改善

### 1.1 個人ごとのなくしもの傾向（Per-Person Lost Item Tendencies）

- **現状**： 分析タブは、自ユーザの記録（または共有データ単位）から傾向を集計する。
- **改修済みの土台**： `_build_analysis_sections(records)` として、**任意の records 集合**を入力に取って分析セクションを生成する構造にリファクタリング済み（per-person 対応の基盤）。
- **今後の改善案**：
  - 複数人で共有する際に、**人ごと**に「なくしものの傾向」を算出する。
  - 例： 人Aにとっては「スマートフォンは布団の隙間」、人Bにとっては「財布はカバンの中」といった、**個人ごとの傾向サマリー**を分析タブで表示する。
  - カテゴリ別の傾向頻度、傾向の強さ（出現確率）を人物ごとに集計する。

### 1.2 傾向の時系列化・トレンド抽出

- 記録の月次・季節ごとの傾向変化を可視化する。
- どのカテゴリ・どの場所で傾向が増減しているかを把握する。

### 1.3 分析指標の拡張

- 既存の「場所別（部屋>家具>スポット）」分析を軸に、**人物ペルソナ別の傾向分析**を追加する。
- カテゴリ×人物のクロス分析（例： 人Aのスマホ紛失はソファ周辺、人Bの鍵紛失は玄関付近）。

### 1.4 予測エンジン（RWR）の精度向上

- ハイパーパラメータ（`RWR_ALPHA`, `RWR_ITERATIONS`, `LOC_SIM_THRESHOLD` 等）のチューニング。
- 多層グラフ化・確率的RWR（サンプリング平均）の検討。
- 関連スコアの閾値（`RELATED_SCORE_THRESHOLD`）の調整。

## 2. 共有機能との統合

- 複数人で共有する際に、**人ごと**に分析を実行できるようにする。
- 共有データから各人の「なくしもの傾向」を抽出し、分析タブに反映する。

## 3. その他の改善テーマ

- 分析ダブの中身のリニューアル（視認性・情報設計）。
- Flet 0.85.2 / Pyodide の制約に沿った実装の継続。
- PWA・デプロイの安定化。
